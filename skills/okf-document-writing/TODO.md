# Deferred Scope

The following are intentionally excluded from the first draft:

- Integrate an actual reference agent or authoritative OKF specification retrieval.
- Add local policy field value, type, and regex schemas.
- Add local policy type-specific rules, path/glob controls, recursively required reserved-file profiles, and policy provenance or remote references.
- Add deeper semantic validation for recommended metadata and computation/executor/attester contracts.
- Add configurable YAML parser dependency handling and full Markdown link parsing for relative links and complex syntax.
- Add publication, registry submission, remote synchronization, or deployment workflows.
- Add computation execution, reproducibility runners, or verification automation.
