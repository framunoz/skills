# Mermaid Diagram-Type Coverage

This is a manually maintained checklist of Mermaid diagram types from the [official syntax reference index](https://mermaid.js.org/intro/syntax-reference.html). A checked item has a focused skill reference and router registration; an unchecked item awaits both. To register a type, follow the router's [Adding a type](router.md#adding-a-type) workflow, then change its checkbox.
